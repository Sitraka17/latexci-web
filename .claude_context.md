## Parser LaTeX preview (`lib/latex-parser.ts`)

Renderer **deux passes** LaTeX → HTML (preview client uniquement ; la compilation réelle = YToTech). Tests dans `lib/__tests__/`.

**Capacités** : équations/sections numérotées, `\ref/\eqref/\cite`, bibliography, footnotes, figures/tables, listes (imbriquées + `[options]` + `\item[label]`), `\newcommand` **expansé** (pas juste supprimé), title pages, fancyhdr, `\textsuperscript/\textsubscript`, `\parbox/\fbox/\framebox`, environnements layout.

**Détection présentation** : si `\documentclass{beamer}` (ou `\begin{frame}`) → affiche un **encart « Beamer detected » + plan du deck** et renvoie vers ↓ PDF (le preview ne sait pas rendre les slides).

### ⚠️ Pièges du parser (ne pas réintroduire)
1. **Une passe typographique convertit les guillemets droits → courbes APRÈS génération du HTML** → tout attribut HTML généré doit être en **guillemets doubles** (`href="…"`), sinon corruption `=’`.
2. **`\\[1cm]` contient `\[`** que le handler de math display lisait comme ouverture math → il faut neutraliser `\\[<len>]` **avant** le parsing math (`body.replace(/\\\\\*?\s*\[[^\]]*\]/g, "\\\\ ")`). Sinon les title pages sont avalées.
3. RegExp construite via template string : `[\\s\\S]`, pas `[\s\S]`.

## Base de données & RLS (Supabase)

Schéma complet : **`lib/supabase/schema.sql`** (tables `profiles`, `documents`, `document_collaborators` + triggers + RLS). Migrations : `lib/supabase/migrations/`.

`profiles` : `id, email, display_name, avatar_url, stripe_customer_id, subscription_tier, subscription_status, subscription_period_end, word_conversions_this_month, word_conversions_reset_at, created_at, updated_at`.

`documents` : `id, user_id (FK→profiles.id), title, content, is_pinned, tags, share_token, is_public, public_can_edit, …`

### ⚠️ Piège RLS : récursion infinie (corrigé juin 2026)
Les policies collaborateur de `documents` et `document_collaborators` se référençaient mutuellement → `infinite recursion detected in policy for relation "documents"` → **bloque tout read/insert**. Fix : checks inter-tables déplacés dans des **fonctions `SECURITY DEFINER`** (`owns_document`, `is_collaborator`) qui bypassent la RLS de la table lue. Migration idempotente : `lib/supabase/migrations/2026-06-17-fix-rls-recursion.sql` (à exécuter dans le SQL editor Supabase).

### ⚠️ Piège FK : profil manquant
`documents.user_id` → `profiles.id`. Si le trigger `handle_new_user` n'a pas créé le profil (compte pré-existant / DB restaurée), tout insert document échoue. Mitigation côté code : `createDocument` (dashboard) et `saveToCloud` (éditeur) font un **upsert du profil** avant l'insert, et **affichent l'erreur Postgres réelle** (plus de « Failed to create document » générique).

## Collaboration & sauvegarde cloud

- **☁ Save** (éditeur) : persiste un brouillon vers l'espace cloud puis bascule sur `?doc=<id>` (autosave prend le relais). Signed-out → « Sign in to save » avec `?next=`.
- **Team editing** : les collaborateurs invités peuvent ouvrir/éditer (selon permission `view`/`edit`) — la RLS l'autorisait, le client le bloquait avant. Badge « View only ».
- **Liens publics éditables** : `PUT /api/shared/[token]` (rate-limited, exige `is_public` + `public_can_edit`) — sauvegarde réelle des éditions via le token comme capability.
- Ouvrir un doc cloud n'écrase plus le brouillon localStorage.

## Ops & fiabilité

- **Keep-warm cron** : `.github/workflows/keep-warm.yml` ping `/api/health` (Lun & Jeu 09:00 UTC). `/api/health` sonde **les tables `profiles` ET `documents`** (head count) → garde le projet Supabase free-tier « chaud » + sert de probe uptime (échec workflow = alerte). Réponse : `{ok, db, tables:{profiles,documents}, ts}`.
- **Rate limiting** : `lib/rate-limit.ts` (sliding window in-memory) sur les routes BibTeX (DOI/arXiv/PMID/ISBN) et `/api/shared`.
- **Branding** : favicon `app/icon.svg` (monogramme ∫ dégradé), `app/icon.tsx` (PNG 512 PWA), `app/apple-icon.tsx` ; **`favicon.ico` Vercel supprimé**. OG image générée `app/opengraph-image.tsx` (⚠️ Satori exige `display:flex` sur les `<div>` multi-enfants).
